# 订单解析与筛选规则

本文集中说明订单格式、字段修正和失败降级行为，供需要细查的开发者阅读；具体实现和边界以源码及回归测试为准。

订单之间不必留空行。程序会逐块识别“订单号 A100”“温州433255”“S556313”等编号；同一文本块中重复出现学员、科目、费用等字段时，会先调用模型区分粘连订单，再逐条解析。模型只返回行号和复制自原文的开头片段，由本地校验并切回原文；无效边界会保留整段原文并标记待复核。

支持编号后的“加急订单”、表情和“温州线下ZYM…”等混合编号，也支持“地址★／学员★／科目★”字段，以及“辅导地点／课费报酬／时间次数”等组合标题。旧批次中包含多个明确订单编号的卡片会在恢复、刷新结果页或应用筛选时按原文拆开，再在本地提取各条字段；原输入和其他卡片保留，不重复调用模型，修复结果仍需复核。

时薪在本地统一换算：`180/2h` 为 90 元/小时。粘连报价优先使用“每次2小时”“周六下午四小时”等原文证据；缺少证据时，按单次通常不超过9小时拆分末尾时长，例如 `1802h` 为90元/小时、`220-2402h` 为110–120元/小时、`2404h` 为60元/小时。报价中的 `70h`、`150h` 等两位数或末位为0的简写按每小时报价处理；明确的时薪标签和带斜线报价优先，时长冲突时保持待确认。换算依据保存在字段来源中。“150元一个小时”“130一个小时”等写法也支持。多个报价（含后续涨价）全部换算后合并为最低到最高的时薪范围；只要报价可确定，不会因数量多或是区间而变成“时薪未知”。范围跨越最低时薪时为可能匹配，全部低于最低时薪时排除；全部达到最低时薪时，薪资条件通过。已有批次会在结果页刷新或重新应用筛选时按新规则修正，无需再次调用模型。

若部分报价面议或无法换算，仍保留其他已知报价的范围，并标记“部分薪资”待确认，不把已知报价的最高值当成整个订单的最高值。点击“应用筛选”会按原文修正当前批次的薪资、年级、性别要求和时间信息，不会再次调用模型。

支持 `〖学员〗四年级女生` 等括号字段，四年级归为小学。“一周一次”只表示每周1次，不会误识别为周一；“周一到周五”展开为周一至周五，“周六或者周日”表示可任选其一。每次课时长单独显示，例如“一次3小时”为每次3小时；原文未写上下午时仍显示时段待确认，不能把课时长猜成时段。

支持“联系地址／年级性别／辅导科目／学员情况／薪资待遇”格式，“年级性别：初一、六年级、高一”分别归为初中、小学、高中。明确的年级字段优先于学员情况中的描述，学生性别不作为教师性别要求，年级行也不会并入地址或在地址脱敏时被遮盖。旧批次在刷新结果页或点击“应用筛选”后自动按新规则重算。

支持 `【初三科学，鹿城区某大厦】` 等复合标题地址，并保留原始地点和字段来源。本地解析与 DeepSeek 共同识别地址：本地提供明确地址和边界，模型补充当前订单正文中的地址；模型返回值必须逐字匹配原文中的连续片段，不补城市、不改写、不拼接。遗漏同一地址中的“近、约、附近、东侧约500米”等描述时从原文恢复；“龙湾或瓯北”等备选地址整体保留。无法通过校验的模型地址会标记并回退本地规则；无可靠地址时留空待确认。重新筛选及恢复批次时仍校验、保留模型地址，不再次请求模型。已知宣传标题不计为订单，尾部 `S411842-5` 等编号归属当前订单。

地址展示与高德检索词分别处理：保留原文地址，只对检索词去除相对方位、距离文字；返回地标参考区域，不根据“约500米”推算学生坐标。相对地址保留地址范围待确认，旧版相对地址缓存会重新定位；线上订单不自动定位。

支持“两个半小时”“两小时半”“90分钟”和19:00–21:30等写法。“除了下午1–3点”保留为排除窗口并提示具体时间待确认；整天/整段时段明确不可接时才按已知冲突排除。时间字段缺字如“一次小时”会保留待确认，不按报价中的“两小时”补造上课时长。CSV同时导出排除窗口和排除星期。

支持“周日下午1点到3点”“晚上6点半到8点半”、中文数字及冒号钟点；卡片直接显示13:00–15:00等精确时间。不同星期的窗口分别保留，例如周二到周五14:00–20:30、周六周日09:00–17:00。固定安排覆盖全部上课日、每日一个窗口时可据此识别每周次数；备选日期、隔周、弹性窗口、未完整说明的安排不自动推算。各组窗口时长不同则每次课时长待确认，月薪仍保留原报价与时薪待确认，不按平均窗口长度换算。

`wz815`等短编号可作为订单边界，无空行也不会因编号格式遗漏而粘连。“详情”“备注”作为独立字段，不并入地址。“作业辅导”保留为明确科目，可独立筛选。代码升级后当前批次首次打开结果页按已应用条件自动重筛一次，并记录“字段规则升级”；未应用的筛选草稿不影响此次重筛，原日志快照保留。

“周六晚上或周日上午”按完整备选安排筛选，星期与时段不会跨分支拼接。订单字段之间的空行、多行科目也会保留。非法薪资、非法星期和矛盾的模型字段会降级复核；单条本地解析异常会保留原文并继续本批。CSV 对公式前缀和行首控制字符加单引号防护，因此这些单元格的导出值可能比原文多一个保护字符。

订单字段提取时向 DeepSeek 发送地址，姓名和联系方式在本地脱敏；订单边界识别请求仍隐藏详细地址。本地开发日志保留原始订单和详细地址。每条订单独立提取；调用失败会使用本地规则并说明失败类型。模型返回字段空值、待定值会按未知处理；单条模型格式错误不会停用后续订单的模型解析。连续接口故障时使用本地降级，模型切分出的粘连订单也会标记待复核。请在接单前核对原始订单。
