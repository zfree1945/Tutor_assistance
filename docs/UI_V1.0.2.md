# v1.0.2 界面调整

按照确认的排版图统一五个页面：浅蓝侧栏、浅色页面背景、白色圆角卡片、蓝色主按钮和一致的标题层级。主题通过 `.streamlit/config.toml` 配置；卡片、导航与窄屏布局由 `tutor_screen/ui_theme.css` 补充。没有外部字体依赖。

## 页面

- 地图订单预览：点击订单标记打开弹窗，鼠标停留在“查看订单”按钮时，在该标记正右侧显示原始订单 tooltip，移出按钮即隐藏；点击按钮触发卡片联动时仍保持预览。原文保留换行，超长时可将鼠标留在按钮上用滚轮查看；屏幕右侧空间不足时向左避让。原文仅供本地预览，不传入高德查询或标记参数。
- 筛选结果：宽度达到1200px时左侧地图约占44%、右侧为两列连续分组列表，前四单占两行，不分页、不缩放页面。原始订单默认折叠，点击后展开；桌面长原文独立滚动，正文保持14px；1920×1080和1440×1000下对四张展开的长原文订单进行同屏验收。地图随列表滚动保持可见，定位进度和待确认地点在地图下方显示。窄屏沿用地图在上、订单在下、原文默认折叠的排版。“修改筛选条件”返回订单导入页。无地图凭据或无订单时仍保留页面结构；缺少凭据时显示空状态，不显示虚构订单或底图。已定位的明确匹配与可能匹配订单使用现有地图组件，卡片保留直线距离。订单的地址、时间窗口或待确认项特别长时卡片仍允许自然增高，不裁掉结构化信息。
- 模型设置：连接配置与填写说明分栏，手机上上下排列。服务商固定为 DeepSeek，配置自动加密保存，可主动测试连接；填写说明的第一项提供 DeepSeek API Key 创建入口。
- 地图设置：凭据、常用出发点、本机缓存分别成卡。保留原有设置、搜索、保存、删除操作。
- 订单导入：移除顶部三张步骤导航卡片和添加订单卡片底部的清空、开始按钮；文本与上传区域放在统一卡片中。完整的筛选条件卡片紧接在添加订单卡片下方，保留出发点和排序，默认由近到远，重置也恢复此顺序；最大直线距离输入框、限制直线距离和隐藏距离未知订单的勾选项已移除，距离不再用于排除订单。点击下方“应用筛选”统一处理新输入与条件；替换已有批次仍需覆盖确认。
- 开发日志：概览、导入记录和操作快照分区。导入原文默认折叠，完整订单及调试字段继续可查阅和导出。

筛选条件在订单导入页填写，点击“应用筛选”时，新增或修改的输入使用当前草稿解析成新批次；输入未变或没有新输入时只在本地更新已有结果，不重复请求模型。首次解析和已有订单应用筛选成功后都会自动跳到结果页（包括筛选结果为空）；输入验证失败或等待覆盖确认时留在导入页。普通页面切换保留草稿但不应用。点击已定位订单标记会选择对应卡片所在分组；手动切换分组时保留选择。

最近成功解析的完整原文、全部解析订单和已应用条件自动保存在本机。刷新或重启后恢复到订单导入页，原文填回粘贴输入框（包括 TXT 导入），结果可直接查看或重新筛选，不请求模型。清空开发日志保留当前批次的独立快照；失败导入不覆盖上一份成功快照。旧版已解析日志可用于首次迁移，未解析的新草稿不会替换成功批次。

## 暂缓范围

UI 改版时暂缓了地图定位与路线能力。之后按新的需求增加了[筛选后自动定位与七单样例修复](AUTO_MAP_V1.0.2.md)。自动切换默认城市视野、出发点图标与标签的进一步优化等仍留待后续处理。截图中原有的“结果视图”切换、订单详情选择、位置修正和通勤比较面板已从结果页移除，底层服务和已有本机数据保留。
