# 本地数据与外部请求

## 本机保存

运行数据位于项目根目录的 `.local/`，程序首次使用时自动创建。

| 内容 | 保存方式 |
| --- | --- |
| DeepSeek API 配置 | Windows 当前用户 DPAPI 加密 |
| 当前成功批次 | JSON，包含原文、订单字段和已应用条件 |
| 开发日志 | SQLite，包含导入原文、TXT 原始字节及操作快照 |
| 地图凭据 | 地图数据库中的 DPAPI 密文 |
| 常用地点、位置和缓存 | 地图数据库或会话；接口持久缓存默认关闭 |

配置加密与业务数据存储是两件不同的事：JSON 快照、订单日志与地点信息不能视为已经加密。DPAPI 密文依赖保存时的 Windows 用户，不能当作可跨电脑直接使用的配置。

## 外部请求

- **DeepSeek**：提取订单字段与必要的边界信息。发送前按本地规则处理地址和联系方式；原文继续保留在本机。
- **高德地图**：配置后用于底图、地址搜索和地理编码。查询地址需要传给高德，不能把“模型脱敏”理解为地址从不离开本机。
- **浏览器地图组件**：使用 JS API 凭据加载 SDK；Web 服务 Key 由 Python 后端使用。

本地脱敏依赖规则识别，不构成识别所有敏感信息的保证。接单与地址核对仍以原文和当事人确认为准。

## 当前批次和日志

最近成功解析的批次独立于开发日志。重启可以恢复批次，清空日志不会删除当前批次，也不会由当前批次重新建立已清空的日志。失败或空的新解析不会替换上一份成功快照。

CSV 导出只写订单数据，不写模型配置；对可能作为表格公式的单元格添加保护字符，因此部分导出值可能比原文多一个单引号。

## 发布副本

整理副本排除了原项目的 `.git/`、`.venv/`、`.local/`、`.env`、Streamlit 私密配置、个人订单文件、导入日志和历史产物。测试源码及格式回归样例仍保留。

将来运行和测试会重新生成本地文件。`.gitignore` 已覆盖运行数据、数据库、密文、缓存和 `artifacts/`；发布时仍应仅上传源码范围。`scripts/check_project.py` 可检查常见误带文件及文档链接。
