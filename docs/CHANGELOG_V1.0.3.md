# v1.0.3 更新说明

## 地址识别与定位

- 本地解析与 DeepSeek 共同提取明确地址及正文中未标注的上课地址；模型返回地址必须是当前订单原文中的连续片段。
- 保留“近、约、附近、东侧约五百米”等描述，单独生成高德检索词，显示约略参考位置。
- 核对候选地点的城市、区县、行政编码和 POI 标识，减少同名、异地及附属地点误匹配。
- 修复县级市与地级市的层级核验。

## 出发点设置

- 输入关键词后自动显示地点建议，选定确切位置后保存，替代原有两个按钮和独立候选下拉框。
- 修复详细地址被自定义名称覆盖的问题，常用出发点和导入页选项统一显示“名称 · 详细地址 · 城市”；缺少地址的旧记录明确提示。
- 已配置高德凭据但尚未选择出发点时，在订单导入页选择框下方显示红字提醒。

## 源码副本

补齐应用全部 Python 模块、地图与出发点前端资源、主题样式、README、pytest 配置和 Git 规则。排除本机凭据、订单、日志、数据库、运行环境、缓存和历史 Git 数据。测试样例中的原始订单编号与具体地点替换为虚构值，相关断言同步更新。

源码整理和离线自动化测试不代表真实高德服务、模型效果或跨电脑兼容性验收。本目录尚未上传 GitHub；启动包需单独构建并作为 Release 附件发布。
