# v1.0.2 高德订单地图

本版本在原有 Streamlit 应用中增加地图，不使用其他家教项目的源码。首版仅接入高德，天地图、百度与多订单排程尚未实现。项目仍由每位使用者在自己的电脑运行，无账号系统；配置加密沿用 Windows 当前用户 DPAPI。

## 开始使用

1. 在 [高德控制台](https://console.amap.com/dev/key/app) 为自己的账号申请 Web 端（JS API）Key、安全密钥，以及 Web 服务 Key，开通相应接口，并配置访问来源限制。
2. 进入“地图设置”，保存三项凭据和默认城市。保存设置不会测试连接或调用收费接口。JS 凭据由浏览器 SDK 使用；Web 服务 Key 只用于本机 Python 后端，不发送到地图组件，也不写入订单 CSV 或开发日志。
3. 在“搜索出发点”输入关键词，停顿后自动显示地点建议；选择确切位置，填写名称后保存。可分别保存学校、住处等常用地点。
4. 在“订单导入”页的“添加订单”卡片下方筛选条件中选择出发点。点击“应用筛选”后，地图、列表、直线距离与排序同时使用这一个出发点；距离只用于展示和排序，不用于排除订单。草稿改动不会提前改变结果。
5. 凭据与默认城市已配置时，导入后进入结果页或应用筛选，系统自动查询保留订单中尚未缓存的地址，并逐单刷新地图、距离和结果数。原“定位筛选结果”和“开始定位”按钮已删除。一次处理一个地址，显示进度，可取消后续查询，之后可主动继续；已完成的定位保留。失败或额度不足时暂停，只有主动点击“重试未完成定位”才重试。普通刷新、切换页面和筛选草稿改动不重复查询已缓存地址。地理编码与地点搜索可能各产生请求，因此地址数不等于 HTTP 请求数。

## 地图和订单

- 桌面宽屏结果页采用左侧地图、右侧分组订单列表，窄屏采用“顶部地图 → 分组订单列表”；筛选条件统一放在订单导入页的添加订单卡片下方。地图卡片底部依次提供修改筛选条件、导出当前筛选 CSV 和导出明确匹配 CSV。未配置地图凭据时显示空状态；旧的“并排 / 地图 / 列表”视图切换已移除。地图中心以当前已应用出发点为基准，支持“回到出发点”和“查看全部位置”。
- 标记显示原始订单编号，无原始编号则使用内部编号。明确匹配与待确认状态使用不同颜色，选中项突出。低缩放聚合相近位置，同一位置有多个订单时可展开选择，位置坐标不人为偏移。
- 点击标记突出对应卡片；点击卡片“在地图中定位 ↑”选择对应标记。地图只展示已定位的明确匹配与可能匹配订单。弹窗展示科目、年级、报酬、直线距离，不把整条原文发送给浏览器地图 SDK。
- 拖动地图只改变视野，不改变筛选；本版未加入“搜索此区域”。
- 直线距离使用同一 GCJ-02 坐标系在本机计算，不调用高德距离测量接口。小区、学校、车站等约略位置显示“约”，距离不是实际路程。距离大小不会排除订单。
- 道路、街道、乡镇、村庄、社区、商圈等可显示带“约”的区域参考标记；实线边框表示明确匹配，虚线边框表示可能匹配。地标附近、集中候选与逐级回退行为见[区域定位说明](AREA_MAP_V1.0.2.md)。区域参考距离只用于展示，排序按实际距离未知处理。
- 距离未知的订单始终保留，列入“距离待确认”摘要，并留在原有匹配分组中。最大直线距离输入框、限制距离和隐藏未知距离的勾选项均已移除。线上和缺少地址的订单不补造坐标。
- 距离排序在各匹配分组内部体现，未知距离放在组末；默认按距离由近到远，重置条件也恢复此顺序；可主动切换原始顺序。CSV 与地图、卡片使用同一已应用筛选结果，原有 CSV 字段保持兼容。

## 地址识别与已移除界面

页面区分“本批已解析”“当前保留”“地图显示”，地图点数不代表解析订单数。第一节课线上试课不会使有常规线下地址的整单变成线上；保留明确的常规线上安排。编号加标题后的紧凑地址也会提取，例如“【初中全科某区】某街道某小区3栋 初3男生”。这类地址与其他明确地址一样在模型请求前脱敏。

订单选择下拉框、订单位置修正/重新搜索/地图选点、恢复自动定位和通勤比较面板已从筛选结果移除。常用出发点的管理仍在地图设置中保留；已有用户确认位置不会删除。地理编码只得到街道/行政区或多候选时，先尝试地标搜索；唯一候选的名称、城市、原文区县一致时显示地标约略位置，否则尝试区域参考点。连锁店还须核对原文道路，不选搜索排名第一项来代替唯一匹配。只知道道路或更大区域的订单可显示区域参考点；仍无法核对区域、候选分散、纯线上或缺少地址时保留在列表，显示未落点原因和距离未知。旧版未定位缓存会按新规则补查一次，成功位置和用户确认位置直接沿用。

底层定位、位置缓存和路线服务代码保留，供后续地图设计使用；当前页面不提供订单位置修正与通勤查询入口。

## 数据、缓存和费用

地图本机数据文件是 `.local/map_data.sqlite3`，独立于原订单日志。凭据以 DPAPI 密文保存。常用地点、用户确认位置本身以本机结构化数据保留；不自动过期。删除当前订单或开发日志不会删除常用地点。

接口结果默认只保留当前会话。高德服务条款限制未经许可的存储、缓存；只有账号取得相应许可后，才可在设置启用本机持久缓存。关闭该选项会删除磁盘中的接口定位、通勤缓存。可以单独“清除接口定位与通勤缓存”，保留常用出发点和用户确认位置；清理后返回筛选结果时会自动重新定位当前保留订单。删除常用出发点使用各自的删除按钮。

使用者自行申请凭据并确认账号权益，本项目不附带公共密钥、不承诺所有用途免费。额度不足、限流或错误会暂停批量查询，不自动循环重试或购买套餐，不自动切换供应商。高德自身的底图 SDK 请求由其 SDK 管理；后端队列停止不等于控制 SDK 内部的每个瓦片请求。
